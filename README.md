# Hotel Revenue Performance Analysis

## Project Overview

This project analyzes hotel revenue performance using key Revenue Management indicators.

The analysis focuses on occupancy, Average Daily Rate (ADR), Revenue per Available Room (RevPAR), and daily room revenue.

## Objectives

- Calculate daily hotel occupancy.
- Calculate ADR.
- Calculate RevPAR.
- Analyze room revenue by day.
- Identify demand patterns.
- Present results through an interactive Streamlit dashboard.

## Tools

- Python
- Pandas
- Matplotlib
- Streamlit
- CSV
- Visual Studio Code

## Project Files

- `app.py`: Interactive Streamlit application.
- `hotel_revenue_analysis.py`: Main analysis script.
- `hotel_data.csv`: Hotel dataset used in the analysis.

## Main Features

- Occupancy calculation.
- ADR calculation.
- RevPAR calculation.
- Revenue analysis.
- Interactive charts.
- CSV file upload.
- Automatic conclusions.
- Data visualization.

## Business Value

This project demonstrates how data analysis can support hotel Revenue Management decisions by identifying occupancy patterns, revenue performance, and potential commercial opportunities.

## How to Run the Project

Install the required libraries:

```bash
pip install pandas matplotlib streamlit

```bash
streamlit run app.py
```

The application will open in the browser.
